# Pinned Baileys patch

`baileys@7.0.0-rc14` remains pinned in package.json. pnpm applies `baileys@7.0.0-rc14.patch` during frozen installation, including `--ignore-scripts`; the patch and its hash are recorded in the lockfile. This uses [pnpm's dependency patch mechanism](https://pnpm.io/10.x/cli/patch), so installation needs neither a private experimental tarball nor an SDK build step.

The patch contains the 32 compiled JavaScript, declaration and source-map files that differ between the published rc14 package and the build of [gabrielMalonso/Baileys at 43055207616cac61c8c4ae95f7c29506df4a1f8c](https://github.com/gabrielMalonso/Baileys/commit/43055207616cac61c8c4ae95f7c29506df4a1f8c). Sources are proposed in [SDK PR #1](https://github.com/gabrielMalonso/Baileys/pull/1), [SDK PR #2](https://github.com/gabrielMalonso/Baileys/pull/2) and [SDK PR #3](https://github.com/gabrielMalonso/Baileys/pull/3), with the review correction in [SDK PR #4](https://github.com/gabrielMalonso/Baileys/pull/4). The fork also includes upstream's WIN_HYBRID platform change. The preflight sync commits outside the outgoing patch transaction, so a listener follow-up cannot reuse an already committed transaction context. Direct-chat receipt times now use `message-receipt.update`, leaving message timestamps unchanged. No dependency versions, credentials, Signal flows, MAC-verification defaults or generated WAProto bindings are changed by the patch.

To regenerate, use an isolated fork checkout at that exact commit, install with Corepack/Yarn 4.9.2 using `--immutable --mode=skip-build`, and run `corepack yarn build`. In an isolated CLI checkout, run `pnpm patch baileys@7.0.0-rc14 --ignore-existing --edit-dir .tmp/baileys-patch`, copy the fork's built `lib/` files into that editable package, and run `pnpm patch-commit .tmp/baileys-patch --patches-dir patches`. Keep generated changes separate from CLI behavior changes and review the diff; do not edit an installed package in place. Validate with `pnpm install --frozen-lockfile --ignore-scripts` and the contributor checks.

`test/baileys-patch.test.ts` exercises the installed package with fictional encrypted fixtures and MAC verification enabled. It checks that retiring an old record cannot reverse the new read/archive action, including the final hash/map. The SDK's complete fixture suite passed 482 tests at the pinned commit; CLI tests separately cover the response event integration and queue projection. No live session is used by these tests.
