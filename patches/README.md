# Pinned Baileys patch

`baileys@7.0.0-rc14` remains pinned in package.json. pnpm applies `baileys@7.0.0-rc14.patch` during frozen installation, including `--ignore-scripts`; the patch and its hash are recorded in the lockfile. This uses [pnpm's dependency patch mechanism](https://pnpm.io/10.x/cli/patch), so installation needs neither a private experimental tarball nor an SDK build step.

The patch contains the 30 compiled JavaScript, declaration and source-map files that differ between the published rc14 package and the build of [gabrielMalonso/Baileys at e767c6aa5c18fbf48c4e3b2cb5ddacbf45daa578](https://github.com/gabrielMalonso/Baileys/commit/e767c6aa5c18fbf48c4e3b2cb5ddacbf45daa578). Sources are reviewed in [SDK PR #1](https://github.com/gabrielMalonso/Baileys/pull/1) and [SDK PR #2](https://github.com/gabrielMalonso/Baileys/pull/2). The fork also includes upstream's WIN_HYBRID platform change. No dependency versions, credentials, Signal flows, MAC-verification defaults or generated WAProto bindings are changed by the patch.

To regenerate, use an isolated fork checkout at that exact commit, install with Corepack/Yarn 4.9.2 using `--immutable --mode=skip-build`, and run `corepack yarn build`. In an isolated CLI checkout, run `pnpm patch baileys@7.0.0-rc14 --ignore-existing --edit-dir .tmp/baileys-patch`, copy the fork's built `lib/` files into that editable package, and run `pnpm patch-commit .tmp/baileys-patch --patches-dir patches`. Keep generated changes separate from CLI behavior changes and review the diff; do not edit an installed package in place. Validate with `pnpm install --frozen-lockfile --ignore-scripts` and the contributor checks.

`test/baileys-patch.test.ts` exercises the installed package with fictional encrypted fixtures and MAC verification enabled. It checks that retiring an old record cannot reverse the new read/archive action, including the final hash/map. The SDK's complete fixture suite passed 469 tests at the pinned commit; CLI tests separately cover the response event integration and queue projection. No live session is used by these tests.
